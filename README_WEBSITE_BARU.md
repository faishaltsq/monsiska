## 🎨 Design Specifications

### Color Palette
```
Primary Dark:     #1a3a52  (Headers, Background, Trust)
Primary Medium:   #2d5a7b  (Gradients)
Accent Blue:      #2563eb  (CTAs, Interactive)
Background:       #f8f9fa  (Light, Clean)
Surface:          #ffffff  (Cards, Content)
Neutral Gray:     #757575  (Secondary Text)
```

### Typography
- **Headings**: Bold (700), 2.5rem-3rem
- **Body**: Regular (400), 1rem
- **Line Height**: 1.6 (readability)
- **Font**: Inter (professional, modern)

### Spacing
- **Container Max**: 80rem
- **Section Padding**: 4-6rem vertical
- **Gap Between Cards**: 1.5-2rem
- **Mobile Padding**: 1rem horizontal

- Ensure environment variables set
- Test di production URL
